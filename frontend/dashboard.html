Execution studio

The selected domain drives every source mode below. Camera and image use the infer endpoint, video uses upload run, and RTSP starts a live pipeline stream.

Camera

Camera mode captures browser frames and sends them through the full pipeline one frame at a time. This is the cleanest browser-side path when you do not have a backend camera source stage.

Image mode posts directly to the infer endpoint and renders the returned pipeline output summary.

Video mode plays the file in-browser and streams frames through the live WS endpoint — bounding boxes and face signals update on the overlay in real time.

RTSP runs as a long-lived backend stream. The dashboard shows status and events, but browser playback still depends on any separate restreaming component you choose to run.
