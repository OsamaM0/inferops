MODEL PREPARATION

Checkpoint → validated ONNX

RF-DETR detection models. Provide the trained checkpoint and preserve the project's class order. Conversion checks every weight, PyTorch foreground parity and independent batches before marking an export ready.

Exports are versioned separately. After validation, select the artifact in Configuration; Triton requires repository preparation and an explicit reload.

Camera

Camera mode captures browser frames and sends them through the full pipeline one frame at a time. This is the cleanest browser-side path when you do not have a backend camera source stage.

Image mode posts directly to the infer endpoint and renders the returned pipeline output summary.

Video mode plays the file in-browser and streams frames through the live WS endpoint — bounding boxes and face signals update on the overlay in real time.

Analyze all frames uploads the complete video and waits for alerts, JSON records, snapshots and triggered clips to be saved in the configured evidence storage.

Connect to see the active CPU, CUDA or Triton mode.

RTSP runs as a long-lived backend stream. The dashboard shows status and events, but browser playback still depends on any separate restreaming component you choose to run.
