Contracts behind the drawings

  • Internal session identity scopes temporal state; external stream names can repeat.
  • Media time drives rules and evidence. Monotonic time drives local deadlines. Database UTC drives durable scheduling.
  • PostgreSQL commits acceptance. Persistent disk holds artifacts by default; S3/MinIO is optional. The spool holds recoverable capture material. Optional Redpanda transports messages.
  • Delivery is at least once. Consumers deduplicate durable effects by stable event ID.
  • The deployment supports one active application owner per database/spool bundle, or the explicit static-workers overlay with scoped ownership.
  • Missing footage remains explicit through coverage, reason codes and Incomplete/Failed states.
